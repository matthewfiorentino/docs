## Purpose and scope

This SOP defines the standards for designing Case Report Forms (CRFs) for Sponsor-Investigator studies. CRFs are printed or electronic documents designed to ensure that all data required by the protocol are captured and reported on each trial subject.

This SOP is applicable to Sponsor-Investigator studies where CRF design is the responsibility of the Sponsor-Investigator and data management personnel.

---

## Responsibilities

The **Sponsor-Investigator** is responsible for ensuring that CRF design meets all applicable regulatory, ICH-GCP, and local requirements. Responsibilities may be delegated to appropriately trained team members.

---

## Procedure

### 5.1 General principles

**5.1.1** The CRF is a printed or electronic document designed to ensure that all data required by the protocol are captured and reported to the Sponsor-Investigator on each trial subject. Only data defined in the protocol will be entered in the CRF.

**5.1.2** CRF design must be completed and reviewed against the study protocol and the Data Management Plan (SOP-CR-103) before database setup begins → SOP-CR-104.

**5.1.3** Each CRF field must map to a source document or source data entry point. Fields that cannot be sourced must be justified in the Data Management Plan.

### 5.2 CRF sections

Depending on the data required by the study protocol, a standard CRF may include, but is not limited to, the following sections:

| CRF Section | Purpose |
|---|---|
| Site and participant identification | Links data to a specific site and participant |
| Visit number and date | Identifies the visit and date of data collection |
| Randomization/Registration form | Documents randomization assignment |
| Patient Demographic form | Captures basic demographic information |
| Patient Characteristics form | Study-specific baseline characteristics |
| Eligibility form | Documents inclusion/exclusion criteria assessment |
| Baseline/Screening form | Pre-treatment assessments |
| Treatment form | Treatment, doses, administration routes, frequency, escalations/reductions |
| Vital Signs form | Blood pressure, heart rate, temperature, weight, height |
| ECG form | Electrocardiogram results (if applicable) |
| Physical Exam form | Physical examination findings |
| Laboratory Evaluation (tests) form | Laboratory test results |
| Imaging form | Radiology/imaging results (if applicable) |
| Medical History (including relapse/recurrence form) | Medical history and relevant events |
| Prior and Concomitant Medication log | All medications taken before and during the study |
| Adverse Event form | All adverse events observed during the study |
| SAE Reporting form | Serious adverse event documentation |
| Other Important Safety Issues Reporting form | Any other safety concerns |
| Follow-up forms | Post-treatment follow-up assessments |
| Patient Completion form | Documents date, reason, and circumstances for cessation of visits/data collection (withdrawal, death, progression, or other) |
| End of Study (EOS) form | Final study visit documentation |
| End of Treatment form | End of treatment documentation |
| Investigator date sign-off form | QI/PI sign-off on completed CRFs |

### 5.3 Version control

**5.3.1** Apply version control to all CRFs. Each version must have a version number and date clearly indicated on each page.

**5.3.2** Any change to a CRF after study start must be documented, version-stamped, and filed in the TMF/ISF. Communicate CRF version changes to all affected data entry personnel.

**5.3.3** Superseded CRF versions must be retained in the TMF for audit purposes.

### 5.4 Electronic CRFs (eCRFs)

**5.4.1** Electronic CRFs must comply with 21 CFR Part 11 or equivalent electronic records requirements → SOP-CR-014 and SOP-CR-104.

**5.4.2** The eCRF system must maintain a complete audit trail of all entries, edits, and deletions with user identifier, date, and time.
