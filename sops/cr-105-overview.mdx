# Database Maintenance and Management

<Badge color="gray">SOP-CR-105_04</Badge> <Badge color="gray">Version 04</Badge> <Badge color="green">Effective 01 Sep 2018</Badge> <Badge color="blue">Sponsor-Investigator</Badge>

<Note>
This SOP describes the management and maintenance of the study database from database launch until database lock, to ensure accurate, reliable, complete, and secure electronic data. It applies to all study databases managed at the RI-MUHC and to those personnel responsible for database management and maintenance.

## Key points

- The database must be **backed up** at a frequency sufficient to prevent data loss, using a method that ensures backups are recoverable. Backup logs must be maintained.
- **User access must be reviewed** at regular intervals and updated promptly when team members join, change roles, or leave the study. Removed users must be logged.
- **Data validation checks** must be run routinely to identify missing data, out-of-range values, and cross-field inconsistencies. Findings must be queried and resolved in a timely manner.
- Any **system issue that could affect data integrity** must be documented, assessed for impact, and corrected. All data entries made during the affected period must be reviewed and verified.
- All database changes (including query resolutions, data corrections, and user access changes) must be captured in the **audit trail** with user identifier, date, time, original value, and reason for change.
- Prepare for **database lock** ([SOP-CR-107](/sops/cr-107)) by ensuring all data are entered, all queries resolved, all protocol deviations documented, and all validation checks completed.
