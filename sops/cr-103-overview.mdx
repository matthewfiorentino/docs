# Data Management Plan

<Note>
This SOP identifies the need for a Data Management Plan (DMP) and describes which parties are applicable, the purpose, the process for creating a DMP, and its essential components. It applies to all Data Management personnel and other research team members responsible for authoring or versioning a Data Management Plan for Sponsor-Investigator studies.

## Key points

- The DMP must specify: the **data collection method** (paper <Tooltip tip="Document designed to record all protocol-required information to be reported to the sponsor for each participant." headline="Case Report Form (CRF)" cta="Full definition" href="/kb/glossary#crf">CRF</Tooltip>, EDC/eCRF, or both), the source data verification approach, the data validation rules, the query management process, and the data transfer procedures if applicable.
- The DMP must align with the **protocol** ([SOP-CR-102](/sops/cr-102)) and the **database setup plan** ([SOP-CR-104](/sops/cr-104)). Changes to one document typically require updates to the others.
- The DMP must define **roles and responsibilities** for data management activities, including who may enter, edit, query, and approve data.
- The DMP must address data security, backup procedures, and access controls.
- The completed DMP must be **version-controlled** and filed in the <Tooltip tip="The sponsor's collection of documentation demonstrating compliance across all study sites." headline="Trial Master File (TMF)" cta="Full definition" href="/kb/glossary#tmf">Trial Master File</Tooltip> (TMF). All revisions must be documented with a new version number and date.
- The DMP must be in place and approved **before** the database is built → [SOP-CR-104](/sops/cr-104).
