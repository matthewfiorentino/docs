Before you spend time planning a study, answer one question first: **does this project need REB review at all?** Most clinical research does. Some projects that look like research — chart reviews, process audits, evaluations of standard care — qualify as **quality assurance or quality improvement (QA/QI)** under [TCPS2 Article 2.5](https://ethics.gc.ca/eng/tcps2-eptc2_2022_chapter2-chapitre2.html) and are exempt from REB review. Submitting a QA/QI project for ethics review costs time and creates the wrong file in the wrong place. Skipping ethics review for what is actually research is far worse — the work cannot be published, cannot be funded, and may need to be redone.

The MUHC Centre for Applied Ethics (CAE) publishes a [Research vs QA/QI Screening Tool](https://muhc.ca/cae/page/templates-consent-forms) (Word document) that is the canonical version of this decision aid. The interactive tool on this page replicates the same logic so you can work through it in your browser.

<Tip>
  Already confident this is research? Skip to [My Study Roadmap](/my-roadmap) to generate your personalized startup checklist.
</Tip>

## The distinction

**Research** is defined by TCPS2 as *"an undertaking intended to extend knowledge through a disciplined inquiry and/or systematic investigation."* The aim is **generalizable knowledge** — findings that can withstand the scrutiny of the relevant research community and inform practice beyond the local setting. Research involving human participants requires REB review and approval at the MUHC.

**Quality assurance / quality improvement** projects aim to **introduce changes that improve patient outcomes, system performance, or professional development at the local institution**. They often implement already-established best practices using methods like Plan-Do-Study-Act cycles, and place no additional burden on participants beyond standard care. Under [TCPS2 Article 2.5](https://ethics.gc.ca/eng/tcps2-eptc2_2022_chapter2-chapitre2.html), QA/QI projects are **exempt from REB review**.

<Note>
  Research and QA/QI sit on a continuum. A single project can carry features of both. The screening tool below was designed to help with this exact ambiguity. **The MUHC REB retains the right to make the ultimate determination** regardless of what the tool indicates.
</Note>

A few common questions before you start:

<AccordionGroup>
  <Accordion title="Can a retrospective chart review be QA/QI?">
    Sometimes. The objective and intent of the project are the determining factors. Many chart-review projects are in fact **Health Records Research (HRR)** and must be submitted to the REB via Nagano using the [CAE HRR protocol template](https://muhc.ca/cae/page/templates-consent-forms). Complete the screening tool to decide.
  </Accordion>
  <Accordion title="Do I automatically need REB review if I intend to publish?">
    No. Per TCPS2, *"intent or ability to publish findings are not factors that determine whether an activity is research requiring ethics review."* Some QA/QI projects are publishable; some research projects are not. Publishability is independent of the research-versus-QA/QI question.
  </Accordion>
  <Accordion title="Who is ultimately responsible for the decision?">
    The TCPS2 instructs the REB to be consulted *"when in doubt."* You are responsible for the accuracy and completeness of the responses you provide here. The REB makes the final determination if your project is submitted.
  </Accordion>
  <Accordion title="What if my project starts as QA/QI and evolves into research?">
    You are responsible for obtaining REB review at the point of change. An exemption letter for the original QA/QI scope does not extend to the new research aspects.
  </Accordion>
  <Accordion title="Special considerations for QA/QI projects">
    Even when exempt from REB review, QA/QI projects must respect three additional obligations:
    - **Patient health information without consent** requires a **Privacy Impact Assessment (EFVP / évaluation des facteurs relatifs à la vie privée)**. Initiate directly with [efvp@muhc.mcgill.ca](mailto:efvp@muhc.mcgill.ca).
    - **Hospital resources** require authorization from the appropriate responsible authorities. Initiate directly.
    - **Eeyou/Eenou (Cree) populations**: declare the project to the Cree Board of Health and Social Services of James Bay at [18ctr.research.committee@ssss.gouv.qc.ca](mailto:18ctr.research.committee@ssss.gouv.qc.ca).
  </Accordion>
</AccordionGroup>

export const IsItResearchTool = () => {
  useEffect(() => {
    var _cancelled = false;

    var QUESTIONS = {
      A: [
        { id: 'q1', text: 'Does the project involve the use of an experimental medical device, drug, or natural health product that requires approval from Health Canada?' },
        { id: 'q2', text: 'Does the project involve the off-label use of an existing drug?' },

      ],
      B: [
        { id: 'q5', text: 'Does the project seek to control for variables or confounders to promote generalizability?' },
        { id: 'q6', text: 'Will you determine the number of participants via formal statistical justifications, power calculations, or expected thematic saturation levels?' },
        { id: 'q7', text: 'Is the project a pilot study or proof of concept designed to support a future, larger research project?' }
      ],
      C: [
        { id: 'q8',  text: 'Is the project the result of a department-wide initiative at the MUHC (e.g., with concerted support from colleagues)?' },
        { id: 'q9',  text: 'Is the immediate goal of the project to improve a process, program, system, or MUHC performance — or to evaluate or implement a best practice at the MUHC?' },
        { id: 'q11', text: 'Do you have reasons to expect that the results of your project will be quickly integrated into local practices at the MUHC?' },
        { id: 'q12', text: 'Would the project still be done even if there were no opportunity to publish the results, or if the results might not be applicable anywhere else?' }
      ]
    };

    function getAnswers() {
      var out = {};
      ['A','B','C'].forEach(function(grp) {
        QUESTIONS[grp].forEach(function(q) {
          var checked = document.querySelector('input[name="' + q.id + '"]:checked');
          out[q.id] = checked ? checked.value : null;
        });
      });
      return out;
    }

    function evaluate(a) {
      var aYes = QUESTIONS.A.filter(function(q) { return a[q.id] === 'yes'; });
      var bYes = QUESTIONS.B.filter(function(q) { return a[q.id] === 'yes'; }).length;
      var cYes = QUESTIONS.C.filter(function(q) { return a[q.id] === 'yes'; }).length;
      var aAnswered = QUESTIONS.A.filter(function(q) { return a[q.id] !== null; }).length;
      var totalAnswered = aAnswered +
        QUESTIONS.B.filter(function(q) { return a[q.id] !== null; }).length +
        QUESTIONS.C.filter(function(q) { return a[q.id] !== null; }).length;
      if (totalAnswered === 0) return { status: 'empty' };
      if (aYes.length > 0) return { status: 'reb-required', triggers: aYes.map(function(q) { return q.text; }), bYes: bYes, cYes: cYes };
      if (aAnswered < QUESTIONS.A.length) return { status: 'incomplete-a', missing: QUESTIONS.A.length - aAnswered };
      if (bYes === 0 && cYes === 0) return { status: 'unclear-no-signal', bYes: bYes, cYes: cYes };
      if (bYes >= cYes + 2) return { status: 'likely-research', bYes: bYes, cYes: cYes };
      if (cYes >= bYes + 2) return { status: 'likely-qaqi', bYes: bYes, cYes: cYes };
      return { status: 'unclear-mixed', bYes: bYes, cYes: cYes };
    }

        }).join('');
      }
      return '<div class="iir-q-group">' +
          '<div class="iir-q-group-hdr"><span class="iir-q-group-letter iir-letter-a">A</span> Definitive REB triggers <span class="iir-q-group-note">any YES = REB submission required</span></div>' +
          block(QUESTIONS.A, 1) +
        '</div>' +
        '<div class="iir-q-group">' +
          '<div class="iir-q-group-hdr"><span class="iir-q-group-letter iir-letter-b">B</span> Suggestive of research <span class="iir-q-group-note">YES answers point to research</span></div>' +
          block(QUESTIONS.B, 5) +
        '</div>' +
        '<div class="iir-q-group">' +
          '<div class="iir-q-group-hdr"><span class="iir-q-group-letter iir-letter-c">C</span> Suggestive of QA/QI <span class="iir-q-group-note">YES answers point to QA/QI</span></div>' +
          block(QUESTIONS.C, 8) +
        '</div>';
    }

    function init() {
      if (_cancelled) return;
      var qContainer = document.getElementById('iir-questions');
      if (!qContainer) return;
      qContainer.innerHTML = buildQuestionsHtml();
      document.querySelectorAll('.iir-q-row input[type="radio"]').forEach(function(input) {
        input.addEventListener('change', function() {
          var row = this.closest('.iir-q-row');
          row.classList.remove('answered-yes', 'answered-no');
          row.classList.add(this.value === 'yes' ? 'answered-yes' : 'answered-no');
        });
      });
      document.getElementById('iir-submit-btn').addEventListener('click', function() {
        renderResult(evaluate(getAnswers()));
      });
      document.getElementById('iir-reset-top-btn').addEventListener('click', resetAll);
    }

    var _attempts = 0;
    function tryInit() {
      if (_cancelled) return;
      _attempts++;
      if (!document.getElementById('iir-submit-btn')) {
        if (_attempts < 40) setTimeout(tryInit, 75);
        return;
      }
      init();
    }
    tryInit();

    return function() { _cancelled = true; };
  }, []);

  return (
    <>
      <style dangerouslySetInnerHTML={{__html: CSS}} />
      <div dangerouslySetInnerHTML={{__html: ToolHTML}} />
    </>
  );
};

## Authoritative source

This tool replicates the MUHC Centre for Applied Ethics **Research vs Quality Assurance/Improvement (QA/QI) Screening Tool**. The canonical Word document is published on the [CAE Templates page](https://muhc.ca/cae/page/templates-consent-forms) and is the version the REB references when issuing exemption letters. If you need to submit a completed form to the REB — for an exemption letter or a formal determination — download and complete the CAE document directly.

For questions about whether a project requires REB review, contact the REB at extension 36077 or [reb@muhc.mcgill.ca](mailto:reb@muhc.mcgill.ca). Ethical concerns related to QA/QI projects (not requiring REB review) should be directed to the [Centre for Applied Ethics](mailto:cae@muhc.mcgill.ca).
