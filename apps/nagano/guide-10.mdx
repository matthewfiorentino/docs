# F11 Part 8 — Project Files

The Project Files section of the F11 is where you upload all study documents for review.

## Part 8: Project Files

This part contains a dedicated upload screen for each document type — protocol, consent forms, recruitment materials, regulatory documents, and more. Reviewers use these files to assess your study, so version accuracy matters: every document should show a version date or number within the file itself, and those details must match what you enter in Nagano's version fields.

## Upload slots

Each screen in Project Files corresponds to a document type.

<AccordionGroup>
  <Accordion title="1. Research protocol — required for all studies">
    Upload the protocol with version date, page numbers, and any annexes or appendices.
  </Accordion>
  <Accordion title="2. Informed consent form — if consent is required">
    Upload all participant informed consent form(s). Use the Centre for Applied Ethics (CAE) consent templates as a starting point.

    Plan for French and English versions before final institutional authorization.
  </Accordion>
  <Accordion title="3. Biobank framework — if applicable">
    Upload the biobank framework document with version details if your project includes a biobank component.
  </Accordion>
  <Accordion title="4. Investigator's Brochure — if applicable">
    Upload the most recent Investigator's Brochure (IB) when your project includes an investigational product where an IB applies. For Health Canada–regulated drug trials, a current IB is typically expected.

    The Pharmacy Manual and pharmacy-related documents belong in the **Pharmacy services** screen under Institution-specific evaluation — not here.
  </Accordion>
  <Accordion title="5. Recruitment documents — if applicable">
    Upload all materials used to recruit or approach participants: posters, advertisements, invitation letters, emails, phone scripts, social media text.

    - For multi-site projects: upload only materials used within the RSSS.
    - Plan for French and English versions before final institutional authorization.
  </Accordion>
  <Accordion title="6. Questionnaires and research material — if applicable">
    Upload questionnaires and documents used by participants or the research team: questionnaires, participant diaries, reminder cards, SMS text, team instructions. Include version dates on all documents.
  </Accordion>
  <Accordion title="7. Information for participants — if applicable">
    Upload information sheets, educational materials, and drug or device information sheets provided to participants. Plan for French and English versions before final institutional authorization.
  </Accordion>
  <Accordion title="8. Health Canada documents — if applicable">
    Upload the No Objection Letter (NOL) and any other relevant Health Canada authorization documentation. Check with Health Canada whether your study requires a Clinical Trial Application before submitting.
  </Accordion>
  <Accordion title="9. Letters of collaboration / support — if applicable">
    Upload letters of support or collaboration from external partners or co-investigators. Record the letter date in the field Nagano provides.
  </Accordion>
  <Accordion title="10. Service agreements — if applicable">
    Upload service agreements with departments involved in the study. Record the agreement date in the field Nagano provides.
  </Accordion>
  <Accordion title="11. Other REBs involved — if applicable">
    If another REB has reviewed or approved your study, upload the approval letter and associated approved documents — including consent forms from the other site. Record the approval date in the field Nagano provides.
  </Accordion>
  <Accordion title="12. Supplementary documents — if applicable">
    Upload any other review-relevant documents that do not belong in a dedicated slot above.

    Documents related to feasibility assessments — nursing forms, budgets, departmental authorizations — go in the appropriate screen under Institution-specific evaluation, not here.
  </Accordion>
</AccordionGroup>

---

## Before you leave this section

- ✓ Every uploaded document is the current version.
- ✓ Version date and version number fields are completed wherever Nagano asks — and they match the document itself.
- ✓ Each document is in the correct slot for its type.
- ✓ Any document that needs French and English versions is on your radar for final institutional authorization.
