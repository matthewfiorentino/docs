# Site Monitoring Visit

<Note>
This WI describes the full lifecycle of a Site Monitoring Visit (SMV), covering pre-visit preparation, on-site conduct across nine areas (subject recruitment, consent/eligibility, study conduct, REB, CRF/DCF, IP/device, laboratory, equipment, and ISF), follow-up reporting, regular site contact, and remote monitoring via EDC.

## Key points

- Before every SMV, the monitor reviews the most recent visit reports, open issues, current document versions in use, and the anticipated number of subjects to review.
- A Site Monitoring Visit Confirmation E-mail (Appendix 2) must be sent prior to the visit; both monitor and site personnel sign the Monitoring Visit Log or equivalent on arrival.
- During the visit, the monitor verifies nine areas using the Site Monitoring Visit Report template (Appendix 1): subject recruitment, consent/eligibility, study conduct, REB compliance, CRF/DCF processing, IP/device and randomization, laboratory, equipment calibration, and ISF.
- Source data verification (SDV) is performed as per the Monitoring Plan; AE/SAE reporting compliance is verified with reference to WI-CIM-MO006.
- IP and device monitoring follows WI-CIM-MO005.
- The Site Monitoring Visit Report must be completed within **10 working days**; the follow-up letter (Appendix 3) is sent to the site after final report approval.
- If additional unscheduled visits are required (data integrity, subject safety concerns), prior Sponsor authorization is needed.
- Remote monitoring via EDC review may be performed between on-site visits as specified in the Monitoring Plan.
