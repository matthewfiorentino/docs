# Code Red Emergency Preparation and Code Green Evacuation Plan (MGH Site)

<Note>
This work instruction covers the Code Red (fire) and Code Green (evacuation) emergency procedures for CIM personnel and users at the Montreal General Hospital (MGH) site. It applies the same core principles as the Glen site WI (AD002) but is specific to the MGH floor plan and emergency structure.

## Key points

- **All CIM personnel must never put their lives in peril.** Leave the area if the situation becomes dangerous, regardless of where you are in the emergency process.
- **Code Red Alert** = fire not yet confirmed; fire alarm does not sound. Listen to MUHC public address system.
- **Code Red Alarm** = fire confirmed; alarm sounds; elevators return to ground floor; fire doors close in the affected block.
- **Code Green** = order to evacuate; may be horizontal or vertical depending on instructions.
- If with a patient during an interrupted procedure, stop the procedure if possible and document the interruption in study records.
- If a patient requires mobility assistance for vertical evacuation, move them on blankets in a sitting or lying position.
- Upon return, notify the QI and Sponsor of any study-related interruptions and document required actions.
