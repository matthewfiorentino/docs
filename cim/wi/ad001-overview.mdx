# Code Blue Preparation and Management

<Badge color="gray">WI-CIM-AD001_01</Badge> <Badge color="gray">Version 01</Badge> <Badge color="red">Emergency Preparedness</Badge> <Badge color="blue">All CIM Staff</Badge>

<Note>
This work instruction covers what to do when a medical emergency occurs at the CIM — from recognizing the precursors of a Code Blue to managing the event, documenting it, and conducting a post-event debrief. It also defines the pre-visit safety checks required before any visit involving an investigational product.

## Key points

- Before any visit involving IP administration, qualified trained staff (QTS) must complete **Appendix 1 — Safety Checklist Prior to Study Visit**.
- When a Code Blue is recognized, call for assistance within the CIM, activate the Code Blue button if in a patient room, and call specifying Code Blue (adult or pediatric), site, precise location, department (RI-MUHC CIM), caller name, and callback number.
- Someone must **stay with the individual at all times**. Only the Code Blue Team can deactivate the event once activated.
- Appoint a **Pointer** (directs Code Blue Team inside the CIM) and a **Runner** (gathers additional supplies) immediately.
- Document all aspects of the emergency in **Appendix 3 — Code Blue Emergency Event** and in study source documents; report as an AE or SAE as applicable.
- Notify the Sponsor as soon as possible; notify the Safety Team Lead if the UBEC was used.
- Conduct a **post-event debrief** with all involved personnel; document in a CAPA report as appropriate.
- The QI must ensure awareness of IP side effects and a management plan for adverse drug reactions before every visit.
