## 1 · Purpose and scope {#purpose-and-scope}

This work instruction describes the procedures for identifying a Code Red fire emergency and managing a Code Green evacuation for CIM personnel and users at the Montreal General Hospital (MGH) site. It applies to all personnel on CIM premises at the MGH.

**CIM personnel and CIM users must never put their lives in peril. If the situation becomes dangerous, they must leave the area, regardless of where they are in the emergency preparation and evacuation process.**

---

## 2 · Responsibilities {#responsibilities}

| Role | Responsibilities |
|---|---|
| **All Personnel on CIM Premises** | Know procedures for identifying a Code Red, activating a fire alarm, assisting others, and locating fire extinguishers, manual pull stations, and emergency exits. If with a patient, remain with them and call for assistance if needed. |

## 3 · Terms and definitions {#terms-and-definitions}

| Term / Acronym | Definition |
|---|---|
| Code Red Alert | Code red announced on the MUHC public address system; fire alarm does not sound. Fire not yet confirmed. Magnetic door locks do not release; fire doors close. |
| Code Red Alarm | Code red "confirmed" announced on the MUHC public address system; fire alarm rings. Elevators return to ground floor; fire doors close in the affected block. |
| Fire Door | Specialized doors purpose-built to withstand fires and compartmentalize the building, delaying the spread of fire from one area to another. Typically grey-coloured. |

## 4 · Instructions {#instructions}

### 4.1 Witnessing an incident {#witnessing-an-incident}

A witness discovering fire, heavy smoke, or a potential fire threat must immediately:

- **Step 1 — Save all persons in immediate danger.** Take reasonable actions to remove or shield personnel from the danger zone. Call for help if needed.
- **Step 2 — Alert personnel.** Activate a fire alarm (manual pull station or call). Notify the CIM Emergency Team Lead or CIM Emergency Floor Monitor as soon as possible.
- **Step 3 — Intervene.** If comfortable and safe, attempt to extinguish the fire using a nearby fire extinguisher. Never put yourself in peril — leave the area if the situation becomes dangerous.

### 4.2 Code Red Alert {#code-red-alert}

Fire is not yet confirmed. Listen carefully to the MUHC public address system for further instructions. No evacuation at this stage unless directed.

### 4.3 Code Red Alarm {#code-red-alarm}

Fire has been confirmed. Alarm sounds.

- If the incident is in close proximity to the CIM (e.g., floors above or below your pavilion), note the closest fire exits and route. If the event is in a different pavilion, no immediate action is required.
- Remain or return to your workstation without using the elevators in the affected block. If with a patient, remain with them and await instructions.
- If with a patient undergoing an interrupted procedure (e.g., drug administration, infusion, blood draw), stop the procedure if possible and document the interruption in study records, including activities completed at the point of interruption. If the procedure cannot be interrupted (e.g., infusion), consider moving the patient to an adjacent block.

| Role | Responsibilities |
|---|---|
| **All Personnel** | Remain or return to workstation; stay with patients; listen to MUHC public address system. |

### 4.4 Code Green (Evacuation) {#code-green-evacuation}

An order to evacuate. Applies to Code Red (fire), Code Silver (active shooter), Code Black phase 2 (suspicious package), Code Brown (internal toxic spill), flood, electrical shutdown, or any other circumstance called for by MUHC.

- Assist and guide any visitors (patients, monitors) through the evacuation process.
- Do not use the elevators if the incident is in your block.
- Keep emergency exits clear; avoid picking up personal belongings.
- For persons requiring mobility assistance, move them horizontally to a safe location if possible; for vertical evacuation, move patients on blankets in a sitting or lying position.
- If you require assistance to evacuate a person (mobility limitations or resistant to evacuation), take note of their location and notify security.
- Personnel not affected by the evacuation could make themselves available to assist on other floors as announced.

**After the emergency:** Upon return, notify the QI and Sponsor of any study-related interruptions, detailing the cause and impact (e.g., incomplete dose) and documenting any required actions as instructed by the QI and/or Sponsor.
